# Prompt Dock → Notion

Prompt Dock 是主库，Notion 是查阅副本。只使用用户本次明确提供的文件，不自行扫描并挑选“最新文件”；文件名不能证明内容新旧。

## 首次使用

这是通用分享版，没有预设数据库、账户凭据或用户数据。使用者需连接自己的 Notion 账户，并提供自己的目标数据库链接及 `.promptdock` 文件。缺少目标时先询问；不要按名称猜库、创建同名库或使用别人的历史目标。后续可读取该使用者私有的本地配置，但每次仍须核实目标数据库。未获明确同步请求时只检查，不写入。

## 必须遵守

- 仅通过 Notion 连接器读写，不操作浏览器，不向搜索服务或公共图床发送私密内容。
- 用户明确要求同步本次文件，即授权本次正常新增和安全更新；安装或分享技能不授权自动同步。
- 原备份只读；不修改 Prompt Dock 程序。默认不导入词库和回收站。
- 按 `Prompt Dock ID` 匹配，不用标题去重；不同 ID 同名仍为不同 Prompt。
- 不自动归档或删除 Notion 页面；缺失及回收站项只报告。
- 冲突、旧记录、重复 ID、未知正文保护并提示；无基线且已有内容不同，不默认覆盖。`Notion 备注` 与其他非托管字段永不覆盖。
- 仅保存回读验证成功的基线；中断后查库续传，不能盲目重复创建。
- 私有配置、状态、工作文件、图片、上传票据不存放在技能目录，也不随分享包传播。

## 执行

先完整阅读 [references/workflow.md](references/workflow.md)，按字段映射、三方比较和回读验证操作。

`scripts/sync.py` 提供 prepare、snapshot、plan、commit、upload；Python 3.10+ 标准库即可。prepare、plan、commit 必须传 `--target`，接受数据库 ID 或官方 Notion 数据库链接。基线绑定目标，防止误用另一数据库状态。

先只读准备并说明计划数量。明确要求同步后可执行安全项；冲突单列。目的地不明或无法读取时暂停写入，不绕过连接器权限。

正文：图片（原顺序）→ 普通二级标题 Prompt 及纯文本代码块 → 每个变体的普通二级标题及纯文本代码块。不用折叠，不添加默认版本名称字段，不改写原文。

结束报告新增、更新、跳过、冲突、缺失数量及数据库链接；失败报告实际完成和续传状态。不宣称启用了定时同步。
