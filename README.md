# Prompt Dock

一个本地优先的 Windows Prompt 桌面启动器。

## v0.11.0（Windows 安装版）

- 基于用户确认的 beta.9，保留“Prompt Dock 作者”称呼，恢复其圆角描边标签框；Notion 官方 SVG 保持不变。
- 其他功能逻辑与 beta.9 一致，沿用已验证的快捷调用、输入框定位、预览和粘贴组件。
- 提供 Windows x64 安装向导，可选择安装位置、创建桌面及开始菜单快捷方式。
- 程序标识与数据目录不变；同一 Windows 用户正常安装后沿用原有本地库。安装前请先退出托盘中的旧版，建议另导出一份备份。
- 安装包不含个人 Prompt、图片、词库、设置或备份。新用户仅会看到程序内置的通用示例。
- 普通卸载默认保留本地库。主动删除数据目录、使用清理工具或显式的数据删除参数不属于此保护范围。
- 安装包已在本地生成，不会自动安装或卸载用户当前版本；保留之前的便携测试包。
- 2026-10-19 将这一版源码同步至 GitHub 私密仓库的 main 分支；mac-support 分支独立保留。源码同步不等于发布安装包，既有 Releases 保持不变。

## 功能

- 同一用户只运行一个实例；重复打开会唤出已有窗口，不会再次启动或抢占快捷键
- 唤出快捷键注册失败时保留用户设置并提示冲突，不再自动覆盖为默认值
- 全局快捷键唤出，默认 `Ctrl + Alt + P`
- 可在设置中录制新快捷键，并检测系统级冲突
- 在 Prompt Dock 内按 `Ctrl + K` 聚焦搜索；全局唤出快捷键保持独立
- 在 Prompt Dock 内按 `Ctrl + N` 新建 Prompt，并可在设置中重新录制；不会影响其他软件
- 左侧导航栏和右侧预览栏可以独立收起
- 左右栏支持拖动分隔条调整宽度并自动记住，双击分隔条可恢复默认宽度
- 标签较多时仅滚动左栏标签区，底部设置入口始终可见
- 滚动条平时隐藏，悬停或滚动时淡入，并保留可拖动滑块
- 全套操作图标采用统一的现代简约线性 SVG，并使用更宽松的点击热区
- 可将窗口设为始终置顶
- 超小窗口模式只保留搜索和列表，并自动置顶
- 超小窗口会独立记住最后调整的宽度和高度
- 单击卡片时短暂释放 Prompt Dock 焦点并直接模拟 `Ctrl + V`
- 支持空格分隔的多关键词模糊搜索，可跨标题、使用说明、Prompt 正文、标签和变体内容匹配，并优先展示相关结果
- 独立“词库”模块支持分类、搜索、收藏、最近复制、批量录入、批量移动、批量删除和自动去重；单击词条只复制到剪贴板，不主动切换或粘贴到外部窗口
- 左栏采用随 Prompt / 词库切换的上下文导航：保留一致的快速访问区，并在词库模式直接展示分类；左上主按钮也会切换为当前页面最常用的操作
- 词条提供悬停收藏星标，单击星标不会误触复制；批量管理与组合模式互斥，避免选择状态混淆
- 词库批量录入支持按换行、逗号或顿号拆分；词库搜索框同样显示 `Ctrl + K` 聚焦提示
- 输入框使用系统原生焦点，不再在每次点击时反复激活或重绘窗口；可编辑弹窗只在打开时聚焦一次，并提供明确的输入光标颜色
- Prompt 与词库搜索都采用轻量防抖，连续输入时保持流畅且不会反复刷新界面
- 词库组合模式可选择多个词条，按逗号、空格或换行连接后一次复制；词库数据随 SQLite、导入导出和自动备份一起保存
- 编辑 Prompt 时显示最近使用和常用标签，单击即可添加或移除
- 标签建议在鼠标按下时立即生效，不会因输入框失焦而需要双击
- Prompt 列表支持批量管理，可多选、全选当前结果和确认删除；退出模式时自动清空选择
- 批量操作按钮使用简洁的“全选 / 删除”文字
- 每条 Prompt 可保存独立的“使用说明”，参与搜索和备份，但复制或粘贴时只输出 Prompt 正文
- 标签输入会自动匹配已有标签，也可直接创建新标签；使用“父标签/子标签”即可建立两级分组，左栏以淡色竖线表示层级并只显示子标签名称；筛选标题只显示当前标签，父级关系移到下方说明中
- 在某个标签筛选页新建 Prompt 时会自动预填当前标签；从全部、收藏、搜索结果或词库页面新建时不会误带标签
- 父标签筛选会汇总全部子标签，子标签保持精确筛选；重命名或合并父标签时会同步迁移整个子树
- 标签合并窗口可以选择父标签或子级标签作为目标，并阻止父标签组错误合并到自己的子级
- 左栏双击或右键可重命名标签；右键还可合并或删除标签，删除标签只会解除分类关系，不会删除 Prompt 和图片
- 收藏、最近使用、使用次数排序
- 左栏提供固定的“无标签”入口和实时数量，可快速整理尚未分类的 Prompt，并支持搜索、排序和批量管理
- 删除 Prompt 时先移入回收站并保留文字、标签、变体与图片；可恢复、永久删除，右键“回收站”可确认清空
- 排序使用自定义菜单，与主界面风格一致并支持键盘操作
- 中间栏的小眼睛可开启截图隐私模式，用安全占位线隐藏 Prompt 内容，并可选同时隐藏图片
- 每条 Prompt 最多保存 6 张图片，卡片首图作为封面，右栏完整显示并可切换大图
- 图片支持多选、拖入和直接粘贴；导入时自动压缩至最长边 1600px
- 编辑页面可通过图片右上角拖动手柄调整图片顺序
- 默认版本名称也可自定义，并与其他变体一起显示在版本列表中
- 大图模式以完整适配查看区作为 100%，支持滚轮缩放、拖动画面、方向键切图和双击缩放；可通过半透明按钮、右键菜单或 Ctrl+C 复制/保存当前图片
- 每张卡片可保存多个 Prompt 变体，并在编辑窗口中增删、改名和排序
- 普通窗口悬停卡片时在右栏显示版本列表；超小窗口悬停时弹出版本列表
- 一键复制，或单击卡片直接粘贴到当前输入框
- 右侧预览采用独立正文滚动区，顶部工具与底部操作区固定，长 Prompt 不再触发粘性按钮反复跳动
- 高频复制和粘贴只更新单条 Prompt 的使用记录；搜索输入采用轻量防抖
- `.promptdock` 压缩备份导入与导出，并兼容旧版 JSON 导入
- UUID 与内容哈希双重去重，导入时智能合并
- 自动备份路径可自定义；每天第一次修改 Prompt 库后生成当天的一份备份，更换路径时立即备份，导入前另存保护副本；日备份只保留最近 3 天并检查可用磁盘空间
- Prompt 元数据保存在本地 SQLite，图片按内容哈希独立保存并自动去重
- SQLite 自动维护 WAL，并在正常退出时回收临时日志，避免长期使用后持续增长
- 设置中可查看并清理 Electron 临时缓存，不会触碰 Prompt、图片或备份
- 列表仅加载缩略图，打开预览时才加载原图；删除后会清理不再使用的图片
- 首次升级会自动迁移旧 JSON，并在迁移前保留完整原始副本
- 操作提示使用顶层浮层，在编辑和设置弹窗打开时仍清晰可见
- 新建或编辑 Prompt 时始终从表单顶部开始，不会继承上一次关闭前的滚动位置
- 设置底部提供“关于与作者”页面，展示作者介绍、动态版本信息、GitHub 主页和问题反馈入口，可复制不含个人内容的反馈环境信息

## 配套 Codex Skill：同步到 Notion

可选的 [promptdock-notion-sync](skills/promptdock-notion-sync/SKILL.md) 会把用户提供的 `.promptdock` 备份单向增量同步到其自己的 Notion 数据库；按原始 ID 去重，保护冲突，不自动删除页面。它不是软件内置云同步，也不会定时执行。

- [下载脱敏分享版 ZIP](https://github.com/Kesister/prompt-dock/releases/download/skill-notion-sync-v1.0.0/promptdock-notion-sync-share.zip)
- [查看字段映射与同步规则](skills/promptdock-notion-sync/references/workflow.md)
- 分享版没有预设数据库、个人资料或账户凭据，不随软件安装包自动安装。

首次使用：

1. 将 ZIP 交给 Codex，明确要求安装 `promptdock-notion-sync`，但先不要同步。
2. 安装并连接自己的 Notion 插件／连接器，确保目标数据库有读写权限；不必额外安装通用 Notion 技能。
3. 新开聊天，提供自己的 `.promptdock` 文件和目标数据库链接；当前分享版需先指定已有数据库，会检查并补齐所需字段，不默认创建数据库。
4. 辅助脚本需要 Python 3.10+，可让 Codex 先检查运行环境。

先用以下请求测试：

## 开发运行

```powershell
npm.cmd install
npm.cmd start
```

## 生成 Windows 便携版

```powershell
npm.cmd run dist
```

生成结果位于 `dist` 文件夹：

- `Prompt-Dock-*-portable.exe`：免安装版，每次启动需要先解压运行环境，因此会稍慢。

## 生成 Windows 安装版

```powershell
npm.cmd run dist:installer
```

生成结果位于 `dist` 文件夹：

- `Prompt-Dock-*-Setup.exe`：按向导安装，可选择安装位置并创建桌面和开始菜单快捷方式。
- 安装包只包含程序文件，不包含任何用户 Prompt、图片、设置或备份。
- 安装版与免安装版使用相同的本地数据目录；同一 Windows 用户升级后会继续读取原有资料。
- 普通卸载默认保留本地 Prompt 库，避免误删；新用户首次运行时仅有程序内置的通用示例，不含任何个人资料。

## 操作提示

- 点击右上角关闭按钮只会把程序隐藏到系统托盘。
- 在设置中点击“录制”，再按下新的组合键并保存。
- 若组合键被其他软件占用，原快捷键会继续有效。
- 顶栏的“左栏”“右栏”“置顶”按钮可以快速切换布局。
- 顶栏的 SVG 图标依次控制左栏、右栏、超小窗口和置顶。
- 先点击网页或其他软件的目标输入框，再单击任意 Prompt 卡片即可粘贴。
- 窗口始终保持可聚焦和可唤回，粘贴时不会隐藏 Prompt Dock 或调整目标窗口。
- 标题栏的最小化按钮会把 Prompt Dock 隐藏到系统托盘，避免无边框窗口产生黑色缩略残影。
- `.promptdock` 包含全部 Prompt、标签和所有图片；图片作为独立压缩资源保存，并兼容旧版单图备份。
- 导入时根据 UUID 和正文内容去重，只新增或更新需要的 Prompt，不覆盖本机设置。
- 同一 Prompt 出现无法自动判断的冲突时，可以保留本机、使用导入版本或两个都保留。
- 自动备份每天生成一份，只清理程序生成且不属于最近 3 天的自动备份；手动导出的文件和迁移前副本不会被自动删除。
- 直接粘贴依赖 Windows 的按键模拟；某些以管理员权限运行的软件可能会阻止普通权限程序向其粘贴。
