Windows（x64）

下载 Prompt-Dock-版本号-Setup.exe，按安装向导完成安装，之后可以在软件内一键更新。安装包暂未签名，系统提示时选择继续运行即可。

01

认识界面

三栏布局，一眼看懂

左边是导航与标签，中间是 Prompt 列表，右边是预览与操作。下面的导览会依次点亮每个区域；点下方的步骤条可以直接跳到你关心的部分。

左栏 · 导航

新建、Prompt / 词库切换、快速访问（全部、收藏、最近使用）、标签树、无标签、回收站和设置。

中栏 · 列表

搜索框、批量管理、截图隐私和排序。每张卡片显示缩略图、标题、版本数、摘要与标签。

右栏 · 预览

参考图、使用说明、版本与变体、正文，以及最常用的两个按钮：「复制」和「直接粘贴」。

02

新建 Prompt

把一条好 Prompt 存下来

点「新建 Prompt」或按 。只有标题和正文是必填的，标签、说明、图片和变体随时都能回来补。

标题与快唤简称

标题用来在列表里认出它；简称（可选）建议用简短英文，比如 weekly，搜索和快捷调用时一搜即中。

Prompt 内容

真正会被复制、粘贴的正文。结尾可以留「主题：」「原文：」这样的占位，粘贴后光标正好停在要补充的地方。

使用说明

写给自己的备注：适用模型、参数含义、注意事项。它参与搜索，但不会跟着正文被复制或粘贴。

标签

可以选已有标签，也可以直接输入新标签，用逗号分隔。在某个标签视图里新建时，会自动预填当前标签。

变体

同一张卡片保存多个版本：中文 / English、不同模型的写法……默认版本可以改名，变体可以调整顺序。

参考图片

每条最多 6 张、单张不超过 5 MB，可选择、拖入或直接粘贴截图，自动优化到最长边 1600px。拖动手柄排序，第一张是封面。

03

标签分类

用标签，把 Prompt 分门别类

写成「图像/产品」，它就会出现在「图像」下面。父标签会汇总所有子标签的内容，子标签只显示自己那一类。

折叠与筛选

点标签前的小箭头折叠或展开；点父标签看整个大类，点子标签只看这一类。

重命名

双击标签直接改名，或者右键选择「重命名」。所有用到它的 Prompt 会一起更新。

合并

右键「合并到…」，相关 Prompt 自动改用目标标签并去重。很适合整理「画图」「图像」这类叫法不统一的标签。

删除与无标签

删除标签只会移除标签本身，Prompt 不会被删除。还没分类的内容，统一在「无标签」里找。

04

搜索 · 排序 · 收藏

找得快，才会用得勤

按 随时聚焦搜索框。搜索在本地按关键词匹配（不是 AI 语义搜索），多个关键词用空格隔开即可。

多关键词

关键词之间不需要相邻，可以分散在标题、简称、说明、正文、标签和变体里，全部命中才会显示。

三种排序

最近修改、最常使用、名称。「最常使用」会随着你每次粘贴和复制自动变化，越用越顺手。

收藏与最近使用

在预览区点星标即可收藏；「最近使用」按最后一次使用排序，刚用过的总在最上面。

05

版本与变体

一张卡片，多种写法

同一个需求，不同模型往往要不同写法。与其复制好几张卡片，不如把它们存成同一张卡片的版本——悬停预览，单击即粘贴。

普通窗口：悬停查看

鼠标悬停在多版本卡片上，浮层会列出全部版本；单击其中一个，就只粘贴这一版。

超小窗口：单击弹出

在超小置顶模式里，单击多版本卡片会直接弹出版本列表，选好再粘贴。

预览区

悬停「版本与变体」里的条目即可预览正文，单击直接粘贴；「复制」按钮复制的是当前显示的版本。

06

三种调用方式

把 Prompt 送进任何输入框

Prompt Dock 不是 AI 聊天客户端，它不调用任何模型，只负责把内容送到你正在用的软件里——网页、桌面应用、节点编辑器都可以。

最常用

单击卡片，直接粘贴

先点一下目标软件的输入框，再回到 Prompt Dock 单击卡片，或点预览区的「直接粘贴」。

  • 粘贴到你最后点击的位置
  • 多版本卡片可以先挑版本
  • 只粘贴正文，不带说明和图片
CtrlV
最稳妥

复制，再手动粘贴

点「复制」把当前版本放进剪贴板，自己决定贴到哪里、贴之前要不要先改。

  • 适合要先修改再使用的场景
  • 复制的是当前显示的版本
  • 无法直接粘贴时会自动退回为只复制
CtrlAltSpace
不用切窗口

快捷调用浮窗

在其他软件的输入框里按 ，就地搜索、预览并插入。

  • 测试功能，需先在设置中开启
  • ↑↓ 选择 · → 版本 · Tab 插入 · Esc 取消
  • 识别到的密码框会跳过，不会自动发送
为什么有时只能复制？ 直接粘贴依赖系统的输入接口。遇到密码框、只读区域、粘贴前目标位置发生了变化、自绘控件，或者目标程序以不同权限（比如管理员）运行时，Prompt Dock 会改为只复制并给出提示，这时按 手动粘贴即可。排查顺序：确认输入框可编辑并先点一下 → 检查快捷键是否和其他软件冲突 → 输入法正在选字时先确认上屏。不建议长期以管理员身份运行。
07

实战场景

放进真实的 AI 工作流

下面用五类常见的 AI 工具演示完整流程。画面里的平台都是示意，任何有输入框的软件都可以这样用；演示以 Windows 快捷键为例。

对话类 AI：一个模板，换个主题就能再用

适用于各种网页版、桌面版的对话助手。把写好的模板存进卡片，结尾留一个「主题：」，以后每次只需要补一句话。

  • 先点输入框，再单击卡片：正文直接落在光标处
  • 窗口置顶 + 收起左右栏，像侧边栏一样常驻在旁边
  • 发送键永远由你来按，Prompt Dock 不会自动发送

图像生成：同一个画面，按模型挑版本

Midjourney 带参数的英文、中文模型的自然描述、SDXL 的 tag 串——都放在同一张卡片的不同版本里，参考图也跟着卡片走。

  • 超小置顶模式下，单击多版本卡片会弹出版本列表
  • 缩略图帮你一眼认出要用的那张卡片
  • 在使用说明里写清每个版本适合哪个平台

视频生成：把镜头语言沉淀下来

运镜、光线、节奏这些描述最值得复用。普通窗口里鼠标悬停在卡片上，就能看到它的全部版本。

  • 悬停查看版本，单击某个版本只粘贴那一版
  • 中文平台和英文平台各备一版，按需取用
  • 零散的运镜词，可以放进词库随时组合

音乐生成：用词库拼出风格串

音乐平台的「风格」栏通常是一串关键词。打开词库的组合模式，按顺序点选，一次复制，再粘贴过去。

  • 超小窗口点左上角按钮，侧栏以抽屉方式展开
  • 组合结果可以用逗号、空格或换行连接
  • 词库单击只复制，用 粘贴到目标位置

ComfyUI 等节点平台：浮窗直达文本框

在节点的文本框里按下快捷键，不用切换窗口就能搜索、预览、插入。正向词和负向词可以存成同一张卡片的两个版本。

  • 快捷调用默认关闭，在设置里开启后使用
  • ↑↓ 选择 · → 版本 · ← 返回 · Tab 插入 · Esc 取消
  • 只插入正文，不带说明和图片，也不会替你点运行
08

词库

短词与 Tag 的收纳盒

完整的 Prompt 放卡片，零散的关键词放词库：光线、镜头、风格、负面词……需要时单击复制，或者组合成一串一次复制。

单击复制

单击词条立即复制到剪贴板。注意它只复制，不会直接粘贴到其他软件，需要你手动粘贴。

批量添加

一次粘贴一大段，按换行、逗号、顿号自动拆分，并去除空白和重复的词条。

组合模式

按点选顺序组合多个词条，可选逗号、空格或换行连接，一次复制整串。

分类 · 收藏 · 最近复制

用词库分类整理不同用途；常用词条点星标收藏；「最近复制」帮你找回刚用过的词。

批量管理

多选词条后移动到其他词库或删除。词库删除没有回收站那样的保护，删之前请确认。

09

窗口与托盘

大窗整理，小窗随用

整理时用完整三栏，干活时把它缩成小窗贴在屏幕边。窗口的每种形态都只差一次点击；按 随时唤出。

收起与调宽

左右栏都可以收起；拖动分隔条调整宽度，双击分隔条恢复默认。

超小置顶模式

一键缩成小窗并自动置顶。小窗会单独记住自己的大小，和标准窗口互不影响。

窗口置顶

点图钉让窗口保持在最上层，切到浏览器或其他软件时也不会被挡住。

托盘常驻

关闭和最小化都会把窗口收进系统托盘；完全退出请右键托盘图标。重复打开程序，会直接唤出已经在运行的窗口。

10

截图隐私

截图、录屏前，先点一下

开会共享屏幕、录教程、发截图时，打开「截图隐私」：卡片摘要、预览正文和使用说明都会被遮住，只留下标题与标签。

它不是加密，也不是应用锁。 截图隐私只是遮挡界面显示，数据本身并没有被加密。需要连图片一起隐藏时，在设置里打开「隐私模式同时隐藏图片」。
11

批量管理与回收站

放心清理，误删也能找回

点「批量管理」进入多选，单击卡片勾选；删除的 Prompt 会先进入回收站，随时可以恢复。

多选

单击卡片勾选或取消，也可以全选；处理完点「完成」退出批量模式。

恢复

在回收站里选中 Prompt，可以恢复，也可以单独永久删除。

清空回收站

右键左栏的「回收站」选择「清空回收站…」。清空后无法撤销，只能依靠备份找回。

12

设置 · 备份 · 迁移 · 更新

设好一次，长期放心积累

所有数据都保存在本机：Prompt 存在本地 SQLite 数据库，图片独立存储并自动去重。花一分钟设好自动备份，就可以放心地长期积累。

自动备份

选好备份文件夹后，每天第一次修改 Prompt 库时生成当天快照，当天之后的修改不会刷新它；「立即备份」会写入当天的文件。导入前也会自动生成一份保护副本。系统只保留今天和前两天的 Prompt-Dock-auto-*.promptdock，手动导出的文件不会被清理。

导出与导入

.promptdock 包含 Prompt、标签、变体、说明、图片、词库和回收站。导入时按 ID 与内容自动去重；遇到冲突可以选「保留本机」「使用导入版本」或「两份都保留」。旧版 JSON 也能导入，设备相关的设置不会被覆盖。

换电脑

旧电脑：设置 → 导出 .promptdock；新电脑：安装 Prompt Dock → 设置 → 导入并合并。新装的软件是干净的空库，不会混入别人的内容。

软件更新

Windows 安装版从 v0.11.1 起自动检查新版本（约每 6 小时，可关闭）：查看更新 → 下载更新 → 重启并更新，也可以「稍后再说」。重启前会先导出 Prompt-Dock-before-update-*.promptdock。便携版只提醒不安装；macOS 版需要手动下载新安装包。

从旧版本升级

第一次升级到带内置更新的版本时：先导出备份 → 从托盘菜单退出程序 → 覆盖安装新版本 → 在「关于与作者」里核对版本号。

关于与反馈

「关于与作者」里有反馈入口，还能一键复制版本与系统信息（不含 Prompt 内容）。到问题反馈页或 GitHub 反馈时附上它，定位会快很多。

常见问题

遇到问题，先看这里

先确认目标输入框可以编辑，并且在单击卡片之前先点过它一次。密码框、只读区域、自绘控件，或者目标程序以管理员等不同权限运行时，系统不允许外部程序输入，Prompt Dock 会改为只复制，这时手动粘贴即可。

另外检查一下快捷键是否与其他软件冲突；如果输入法正处于选字状态，先确认上屏再操作。不建议长期以管理员身份运行 Prompt Dock。

macOS 需要授予「直接粘贴」权限：打开系统设置 → 隐私与安全性 → 辅助功能，允许 Prompt Dock。授权前也可以先用「复制」再手动粘贴。

快捷调用是测试功能，默认关闭，需要先在设置里勾选「启用快捷调用」。默认快捷键是 Windows CtrlAltSpace、macOS ⌘⇧Space，如果和其他软件冲突可以重新录制。它不支持在输入框里打 / 或 // 来触发。

小技巧

让它更顺手的 6 个习惯

给常用卡片起个简称

比如 weekly、polish。在快捷调用里输入两三个字母就能命中。

在正文末尾留占位

以「主题：」「原文：」「代码：」结尾，粘贴后光标正好停在要补充的位置。

多模型写法用变体
