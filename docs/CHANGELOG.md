# 更新记录

[返回首页](../README.md) · [下载安装包](https://github.com/Kesister/prompt-dock/releases)

## 0.11.2

- 优化左右栏收放与窄窗口预览的过渡，支持连续反向切换，保持长正文宽度和滚动位置稳定。
- 小窗切换采用内容先淡出、尺寸和布局稳定后再淡入的过渡，减少中间布局跳变；保留尺寸记忆、置顶恢复与导航抽屉动画。
- 接入动画增强层，调整左右栏滑动、菜单、弹窗、标签树及视图切换的过渡节奏。
- 修复快速操作时旧保存结果覆盖新布局状态，以及双栏收起后进入小窗时内容区被挤窄的问题。
- 减少卡片不必要的布局动画，支持系统“减少动态效果”设置，保留栏宽、小窗尺寸与置顶设置。

## 0.11.2 · macOS

- 修复 Edge 等浏览器在输入框已聚焦时仍提示无法定位、只能手动粘贴的问题。
- 改善选中文字替换、文本域、富文本及小窗变体的直接填入。
- 浏览器首次准备输入信息时，快捷浮窗保持快速显示；密码框和只读区域继续保留保护。
- Mac 更新检查独立识别 Mac 发布记录，并提供完整 PKG 安装包下载。Windows 保持 v0.11.1。

## 0.11.1

- 新增软件内更新：自动检查正式版，查看更新说明，点击下载并在完成后重启更新。
- 设置中可手动检查更新或关闭自动检查；下载和安装均需主动点击，「稍后再说」不会自动安装。
- 重启安装前自动导出资料备份；未设置备份目录时使用本机资料目录的 `update-backups`。备份失败会停止安装。
- 便携版提供新版提醒与手动下载入口；开发环境不检查更新。
- 新增 GitHub Actions 发布流程，生成并校验安装包、更新元数据和校验文件，避免覆盖已发布的版本。
- 从 v0.11.0 或更早版本升级时，请先导出 `.promptdock` 备份，从托盘退出旧版，再运行新安装包覆盖安装。此后可使用软件内更新。

## 0.11.0

### 新增与改进

- Windows 快捷调用浮窗：可配置全局快捷键，搜索、选择版本并确认插入。
- 浮窗支持只读预览，展示所选版本正文、使用说明、标签和参考图片；可收起预览。
- 改善首次切换输入框时的定位与焦点交接；无法可靠定位时提供仅复制回退。
- 统一为快捷键调用，移除输入符号触发及软件生效范围设置。
- 重新设计「关于与作者」，提供 GitHub、问题反馈与反馈环境信息复制入口。
- 提供 Windows x64 安装向导；普通卸载默认保留本地资料。

### 使用与升级

- 「快捷调用」默认关闭，需在设置中开启；默认快捷键为 `Ctrl + Alt + Space`。
- 旧版主窗口唤出快捷键、库内容与本地数据目录保持延续。
- 升级前请导出备份，并从托盘退出旧版本。
- 当前安装包未签名，直接粘贴不保证兼容所有输入控件；本次不含 macOS 对应版本。

更早的开发变更可查看 [提交历史](https://github.com/Kesister/prompt-dock/commits/main/)。下载与已知限制以对应 Release 页面为准。
