## 行为

- Windows 与 macOS 共用主程序、界面、SQLite 和 `.promptdock` 格式。
- Mac 主窗口唤出 `⌘⌥P`，搜索 `⌘K`，新建 `⌘N`，图片复制 `⌘C`。快捷调用默认关闭，默认 `⌘⇧Space`，注册冲突时保留旧设置。
- Mac 原生 helper 先完成就绪握手；核对目标应用、可编辑控件、选区和内容后才发送 `⌘V`。识别到密码控件跳过，无法验证或权限不足时保留复制；不发送 Enter。
- 快捷调用使用共享浮窗搜索、版本与只读预览；没有输入符号触发或输入日志。
- 更新使用 MacUpdater，关闭自动下载和退出自动安装，安装前等待保存并核对完整备份。Mac 手动下载只选择固定仓库、对应架构的 DMG。
- 当前是 ad-hoc 试用包，未公证；正式身份验证失败时阻止内置下载安装，保留检查入口与说明。没有改变应用身份或真实资料目录。

## 直接粘贴修复与权限边界

用户反馈 Edge 搜索框只提示复制。正常 LaunchServices 启动旧包和修复包均复现 `accessibilityTrusted: false` 与 `permission`，接收器没有收到输入；系统设置中的旧同名已开启条目没有覆盖当前应用副本。上一轮仅凭终端输入测试宣布直接粘贴通过，缺少这一验证边界。

修复后，主窗口直接粘贴先激活最近的目标应用，再识别并连续核对当前可编辑控件。浮窗继续核对唤出前的严格快照。助手不再在应用失去焦点时读取和缓存输入内容。设置及浮窗补充实际授权状态、准确副本定位和系统授权入口；权限不足时清楚说明原因。

当前修复版的普通启动已验证，授权拒绝路径按预期保留剪贴板。用户明确允许重新授权并完成触控 ID 后，仅重置 `com.codex.promptdock` 的 Accessibility 旧记录，再通过系统设置添加准确的 fix1 副本；正常启动后应用内已显示「辅助功能已授权，可以直接粘贴」。系统日志已证实此前存在代码签名要求不匹配，重复添加和切换旧开关仍绑定旧安装版。

正常 LaunchServices 启动的当前副本已在实际 Edge 地址和搜索栏完成主窗口直接粘贴，完整中文示例逐字回读一致，页面仍为 about:blank，没有提交搜索。快捷浮窗的真实系统热键链路由用户物理按键实测通过：`⌘⇧Space` 唤出、`Tab` 确认后，用户反馈「已直接填入文字」。此项依据用户反馈；主窗口直接粘贴依据原生 AX 逐字回读。不能将终端测试或系统设置中的同名开关代替实际输入回读。详见本地 `outputs/fix1/` 的修复说明和原始证据。

包内只包含应用程序，使用系统原子替换方式覆盖旧应用，禁止把安装目标重定位到工作目录中的同名测试副本。安装没有 preinstall/postinstall 脚本，不清理、导入或重置用户资料。系统要求为 arm64、macOS 12+，与原生助手编译目标一致。

## 快捷浮窗唤出提速

旧实现先等待原生输入框定位，再创建浮窗及加载页面。隔离场景复现了约 1.56 秒的无响应目标等待、约 5.06 秒的助手未就绪等待，以及约 0.44 秒的首次窗口加载。

- Mac 在启用快捷调用时预加载隐藏浮窗，不读取其他应用的输入内容，不注册额外键盘监听。
- 快捷定位请求的 200 毫秒时限覆盖助手启动等待；超过时限后不再发送过期请求。助手晚于首次就绪窗口启动时，后续请求仍可恢复。
- 原生快照设总时限及逐条 AX 消息时限；慢目标不能长期阻塞助手队列。无法确认目标时及时使用复制回退，正常目标仍使用原应用、控件、选区和内容的严格校验。
- 窗口在获得焦点前先收到候选内容，不重复设置相同窗口尺寸，并关闭该 Mac 浮窗的后台节流。

性能测试分别覆盖首次唤出、重复唤出、1200 条合成 SQLite 资料、无响应目标、助手未就绪及延迟就绪恢复。每次正常测试均等待独立接收器真实恢复前台焦点，避免把前一次取消后尚未完成的应用切换当成本次唤出延迟。时间从快捷键回调开始，结束条件是浮窗可见、候选已渲染且搜索框已聚焦；不包含系统接收物理热键之前的耗时。

```sh
node scripts/test-mac-palette-latency.js
node scripts/test-mac-palette-latency.js "/absolute/Prompt Dock.app"
```

最终 arm64 构建在隔离 Cocoa 接收器中，首次唤出 84.9 毫秒，10 次正常唤出中位数 13 毫秒、最大值 84.9 毫秒；1200 条合成资料 46.5 毫秒；无响应目标 145.9 毫秒，助手未就绪 214.6 毫秒。正常样本均保留直接填入，超时样本使用复制回退。该轮助手冷启动本身耗时 4621.4 毫秒，唤出路径不再等待整个启动过程；测试另行验证超过 5 秒的延迟就绪能恢复后续请求。
