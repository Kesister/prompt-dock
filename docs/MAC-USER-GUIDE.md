# Mac 使用说明

[返回首页](../README.md) · [下载 Mac 版](https://github.com/Kesister/prompt-dock/releases/tag/mac-v0.11.2)

Prompt Dock Mac 版支持整理、搜索、预览和复用 Prompt，可保存正文、不同版本、参考图片和常用关键词。资料保存在本机，导出的 `.promptdock` 文件可在 Windows 与 Mac 之间迁移。

## 安装与更新

支持 Apple Silicon（M 系列芯片），系统要求为 macOS 12 或更高版本。

1. 在下载页选择 `.pkg` 安装包。
2. 已安装旧版时，先导出一份 `.promptdock` 备份，再从菜单栏退出 Prompt Dock。
3. 双击安装包，按提示安装到「应用程序」。
4. 在「应用程序」中打开 Prompt Dock。

覆盖安装保留已有资料。从 v0.11.2 起，可在设置中检查 Mac 版更新并打开对应安装包下载。下载完成后手动覆盖安装，暂不支持自动安装新版。v0.11.1 用户请通过本页下载链接升级。

当前 Mac 安装包尚未完成 Apple 开发者签名与公证，系统可能提示来源限制。

## 保存和复用 Prompt

点击「新建 Prompt」填写标题和正文，可按需添加标签、使用说明、图片与变体。按 `⌘K` 搜索，选择内容后复制或直接填入目标输入框。

在其他软件里使用快捷调用：

1. 在设置中开启「快捷调用」。
2. 点进目标输入框，按 `⌘⇧Space`。
3. 在浮窗里搜索、预览并选择版本，按 `Tab` 填入；按 `Esc` 取消。

快捷键可在设置中修改。无法确认可编辑输入位置时，软件会提示仅复制，可返回目标输入框手动粘贴。

## 允许直接填入

直接填入需要 macOS 辅助功能权限。打开 Prompt Dock 设置中的「Mac 直接粘贴权限」，按提示进入「系统设置 → 隐私与安全性 → 辅助功能」，为「应用程序」里的 Prompt Dock 开启权限。

如果更换或升级应用后只提示已复制，请回到应用设置检查授权状态，并按提示重新确认权限。密码框会跳过直接填入，只读区域使用复制。

## 常用快捷键

| 操作 | 默认快捷键 |
| --- | --- |
| 唤出主窗口 | `⌘⌥P` |
| 打开快捷调用浮窗 | `⌘⇧Space`，需先在设置开启 |
| 聚焦搜索 | `⌘K` |
| 新建 Prompt | `⌘N` |
| 选择候选 / 查看变体 / 返回 | `↑ ↓` / `→` / `←` |
| 确认 / 取消 | `Tab` / `Esc` |

## 资料与反馈

换电脑或跨系统迁移时，在旧设备导出 `.promptdock`，再到新设备导入。备份包含完整正文和图片，请妥善保存。

更多资料整理与备份功能见 [使用指南](USER-GUIDE.md)。遇到问题可提交 [GitHub Issue](https://github.com/Kesister/prompt-dock/issues)，附上应用版本、macOS 版本和复现步骤；截图前请遮挡私人内容。
