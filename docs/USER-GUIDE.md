# 使用指南

[返回首页](../README.md)

## 整理 Prompt

- 新建时填写标题和正文。「使用说明」适合记录前提条件、使用方法或适用模型，它参与搜索，但不会随正文复制或粘贴。
- 同一张卡片可以保存多个变体，默认版本也可以改名。普通窗口悬停卡片可查看版本，超小窗口会弹出版本列表。
- 输入标签时可以选择已有标签，也可以创建新标签。用 `工作/写作` 建立父子层级；父标签汇总子级内容，子标签只显示自己的名称。
- 选中某个标签后新建 Prompt，会预填当前标签。标签可双击重命名，也可右键重命名、合并或删除；删除标签不会删除 Prompt。
- 「无标签」用于整理尚未分类的内容。「批量管理」可多选并删除 Prompt，删除后先进入回收站。
- 搜索支持空格分隔的多个关键词，不要求它们相邻，也可以分别出现在标题、说明、正文、标签和变体中；它不是语义搜索或 AI 搜索。

## 图片

每条 Prompt 最多保存 6 张图片，单张导入原图不超过 5 MB。可选择文件、拖入图片或粘贴截图；导入后会优化至最长边 1600px，因此这里不适合作为原始高清图片的唯一存档。

通过编辑页缩略图上的拖动手柄调整顺序，第一张作为封面。点开大图后可用滚轮缩放、拖动画面、方向键切图，也可复制或保存当前图片。

## 快捷调用与直接粘贴

**主窗口：** 默认 `Ctrl + Alt + P` 唤出，适合整理和浏览。先选择外部输入框，再使用卡片或「直接粘贴」。也可以直接复制正文，由自己决定粘贴位置。

**快捷调用：** 需在设置中开启，默认 `Ctrl + Alt + Space`。先点击目标输入框，再唤出浮窗；输入搜索词，预览候选，用 `↑ ↓` 选择、`→` 查看变体、`←` 返回。默认 `Tab` 确认，也可以改为 `Enter`。`Esc` 在变体列表返回上一级，在主列表关闭。

快捷调用只插入所选版本的正文，不带使用说明和参考图片。当前版本已移除符号触发，不监听 `/`、`//` 来启动搜索。

### 为什么有时只能复制？

自动粘贴依赖 Windows 输入接口。密码框、只读区域、目标输入位置发生变化、部分自绘控件或不同权限的软件，可能无法可靠识别或写入。软件会保留仅复制的备用方式，而不是盲目输入。

1. 确认目标输入框可编辑，并先点击它，让光标出现。
2. 检查快捷键是否被其他软件占用；到设置中改成无冲突的组合键。
3. 输入法仍在选字时，先确认候选，再调用。
4. 若提示「仅复制」，回到目标输入框手动 `Ctrl + V`。反馈时提供应用名称、版本、输入框类型及复现步骤，不要提交聊天内容。

不建议为了兼容某个应用而长期以管理员身份运行整个工具。

## 词库

词库适合短词、Tag、风格词和常用词组。单击词条只复制，不主动向外部窗口粘贴。

- 批量添加支持换行、逗号及顿号 `、`，会去除空白和重复词条。
- 分类、收藏与最近复制帮助快速找到内容。
- 组合模式可选择多个词条，以逗号、空格或换行连接后一次复制。
- 批量管理支持移动到其他分类及批量删除。词库删除不要当作 Prompt 回收站的同等保护；重要批量操作前建议导出备份。

## 窗口与退出

左右栏可以收起，拖动分隔条可调整宽度，双击恢复默认宽度。超小窗口独立记住大小，并保持置顶。

关闭按钮与最小化会将窗口隐藏到系统托盘，不代表退出程序。完全退出请使用托盘菜单。重复启动会唤出已有实例；升级前也应先从托盘退出旧版本。

## 数据、备份与恢复

### 手动导出与换电脑

在设置中导出 `.promptdock`，它包含库中的 Prompt、标签、变体、使用说明、图片、词库和回收站资料。导入支持 ID 与内容去重；遇到无法自动处理的冲突，可选择保留本机、使用导入版本或两份都保留。旧 JSON 备份也可导入。

导入库不会直接覆盖当前设备设置。跨电脑迁移时，不要把程序文件与库文件混为一谈；先保留原备份，再在新设备检查内容与图片。

### 自动备份究竟何时发生？

需要先在设置中指定备份目录。当前 v0.11.0 的行为是：

1. 每天第一次修改资料库后，生成当天的一份自动快照。
2. 当天之后的普通修改不会反复刷新这份快照。想把当前最新内容存下来，请手动导出，或使用设置中的立即备份。
3. 立即备份会写入当天的自动备份文件；导入前另生成带时间戳的保护副本。
4. 每次生成自动备份后，检查并清理旧的 `Prompt-Dock-auto-*.promptdock` 文件，按文件修改时间保留今天及之前两天。

因此，“保留 3 天”不等于每隔 3 天清理一次，也不等于永远正好 3 个文件：没有修改的日期可能没有快照，同一天也可能有导入前的保护副本。导入前保护副本属于自动备份，同样会参与清理。**手动导出的文件不在自动清理范围内。**

备份目录建议放在独立磁盘或你自己管理的备份位置；和资料库放在同一块损坏的磁盘上，不能提供磁盘故障保护。

### 删除、卸载与隐私

- 删除 Prompt 后可以到回收站恢复；永久删除或清空回收站后，需要依靠之前的备份恢复。
- 普通卸载默认保留本地库，但主动删除数据目录、清理工具或特殊卸载参数可能绕过这一保护。
- 截图隐私模式只隐藏界面上的内容，不是登录锁，不会加密本地文件或备份。
- 不要把 `.promptdock`、数据库、日志中的个人路径或真实内容提交到公开仓库和 Issue。

## 更新软件

### v0.11.1 及以后

启动后会自动检查 GitHub 上发布的正式版，持续运行时约每 6 小时再检查一次。设置中的「自动检查新版本」可以关闭，偏好即时保存；即使关闭，也可以点击「检查更新」。仅更新代码或文档不会触发程序更新。

发现新版时显示可关闭的提醒。点「查看更新」阅读说明，再点「下载更新」；下载完成后点「重启并更新」。下载和安装均需你主动点击，不会在退出软件时自动安装。「稍后再说」会保留本次已下载的更新；重新启动软件后需要再次检查，下载按钮会复用通过校验的缓存。

重启安装前会先保存当前库，再导出 `Prompt-Dock-before-update-时间-唯一编号.promptdock`。已设置备份目录时存入该目录，否则存入本机资料目录的 `update-backups` 文件夹。升级备份不参与日常 3 天清理，确认新版资料完整后可以自行清理旧升级备份。备份失败会停止安装；请检查空间和目录权限后重试。

检查或下载失败时可以重试，或用「前往下载页面」手动安装。检查更新需要联网；断网不会影响本地使用。便携版提供新版提醒与手动下载，不执行安装版的自动替换。

### v0.11.0 或更早版本首次升级 / 手动安装

旧版还没有更新功能，需要手动安装一次新版：

1. 在「设置」中导出一份 `.promptdock` 备份。
2. 到 [最新 Release](https://github.com/Kesister/prompt-dock/releases/latest) 查看版本号；只有比当前版本更新时才需要下载。选择 `Prompt-Dock-版本号-Setup.exe`，不要下载 `Source code` 或 Notion Skill ZIP 作为安装程序。
3. 从 Windows 系统托盘右键退出 Prompt Dock；只关闭主窗口不算退出。
4. 运行新安装包，沿用原安装位置覆盖安装，一般无需先卸载。使用同一 Windows 用户时，会继续读取原有本地库。
5. 打开软件，在「关于与作者」核对版本，并检查 Prompt、图片和词库是否完整。通常不需要再次导入资料；如内容缺失，先停止清理文件，再用已保留的备份恢复。

使用便携版时，先完全退出旧版，再运行新版 EXE；复制或替换 EXE 不等于备份资料库。

GitHub 文档或源码更新不会自动改变已安装的软件。只有重新构建并发布的新安装包才包含软件内的改动；下载同一个版本的旧安装包不会获得尚未发布的修改。

安装包未做代码签名。下载后可以在 PowerShell 中计算散列，与对应 Release 的值逐字比对：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath "C:\路径\Prompt-Dock-0.11.0-Setup.exe"
```

散列用于检查下载文件是否与发布文件一致，不代替代码签名或系统安全检查。
