将所选 Prompt 移到回收站？

      
将移动 0 条 Prompt；之后仍可从回收站恢复。

      

    

  

  
    

      

      
删除所选词条？

      
将永久删除 0 个词条；词库分类会继续保留。

      

    

  

  
    

      
移动所选词条
将 0 个词条归入另一个词库分类。

      
      
只会改变所属分类，收藏、复制次数和内容都会保留。

      

    

  

  
    

      

      
清空回收站？

      
将永久删除回收站中的 0 条 Prompt。此操作无法撤销，未被使用的图片也会自动清理。

      

    

  

  
    

      

      
删除标签？

      
只会移除标签，不会删除 Prompt 和图片。
